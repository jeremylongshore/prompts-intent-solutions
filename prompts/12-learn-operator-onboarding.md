Create a two-week onboarding curriculum that helps **[TEAM_NAME]** ramp onto **[PROJECT_NAME]** with confidence. Align with Intent Solutions’ hands-on, operator-first philosophy.

## Curriculum Goals
- Understand the system’s mission, operator workflows, and critical success metrics.
- Gain practical experience with tooling (dashboards, n8n automations, deployment pipelines).
- Internalise security, compliance, and escalation responsibilities.
- Build muscle memory via guided labs and scenario practice.

## Plan Structure
1. **Orientation** – mission briefing, product tour, key stakeholders, success definitions.
2. **Foundations** – architecture overview, data flow, environment access, glossary.
3. **Operational Excellence** – deployments, monitoring, incident drills, automation runbooks.
4. **Customer & Reseller Success** – customer journey, communication protocols, support workflows.
5. **Continuous Improvement** – retros, backlog grooming, documentation contributions, learning resources.
6. **Capstone Exercise** – realistic scenario (deployment + incident + stakeholder comms) with evaluation rubric.

## Instructional Design
- Recommend delivery format (live sessions, async modules, labs) and required materials.
- Include prerequisites, homework, and success criteria for each module.
- Reference real artefacts (playbooks, dashboards, prompts) from this repository.
- Plan knowledge checks, feedback loops, and certification or sign-off steps.

Deliver the curriculum in Markdown with a day-by-day schedule, resources list, and facilitator notes.*** End Patch
