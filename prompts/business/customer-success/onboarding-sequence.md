## The Prompt

```
You are a customer onboarding expert who creates systematic welcome sequences that turn new signups into active, successful users.

Product: [PRODUCT_NAME]
Customer segment: [CUSTOMER_TYPE]
Main value proposition: [CORE_BENEFIT]
Typical time to first value: [TIME_TO_VALUE]

Create a 5-email onboarding sequence that:

Email 1 (Day 0 - Welcome):
- Confirms their smart decision to join
- Sets clear expectations for the journey
- Provides immediate quick win (under 5 minutes)

Email 2 (Day 2 - First Success):
- Celebrates any early action taken
- Guides to core feature with specific steps
- Shares one customer success story (similar use case)

Email 3 (Day 5 - Value Demonstration):
- Shows advanced feature that solves bigger problem
- Includes specific use case example
- Offers direct help if needed

Email 4 (Day 10 - Community & Resources):
- Introduces community/support resources
- Shares best practice tips from power users
- Provides checklist for maximizing value

Email 5 (Day 14 - Success Measurement):
- Reviews their progress and achievements
- Suggests next level features or upgrades
- Asks for feedback and offers continued support

Each email:
- Has compelling subject line
- Includes clear single call-to-action
- Feels personal and human
- Is under 200 words
- References specific product features

Variables:
- [PRODUCT_NAME]: Your product/service name
- [CUSTOMER_TYPE]: Target user segment (e.g., "small business owner")
- [CORE_BENEFIT]: Main problem you solve
- [TIME_TO_VALUE]: How long until they see results
```

## Why This Works

1. **Progressive value delivery** - Each email builds on the last
2. **Specific next steps** - Clear, actionable guidance
3. **Social proof integration** - Real customer stories and data
4. **Milestone celebration** - Acknowledges their progress
5. **Community connection** - Reduces isolation and churn
6. **Feedback loop** - Encourages two-way communication

## Advanced Variations

### For High-Touch B2B Products
```
Add personal video messages in emails 2 and 4
Include calendar links for success manager check-ins
Provide industry-specific use case examples
Schedule automated success milestones calls
```

### For Self-Service Products
```
Focus on feature discovery rather than human touch
Include more tutorial links and resource downloads
Add gamification elements (progress bars, badges)
Emphasize community support over direct contact
```

### For Enterprise Customers
```
Include stakeholder-specific messaging
Provide ROI calculators and business case templates
Schedule executive briefings and strategy sessions
Add compliance and security documentation
```

❌ Making emails too long or complex
❌ Focusing on features instead of benefits
❌ Not tracking which emails get opened/clicked
❌ Using same sequence for all customer types
