# Development Prompts

Professional prompts for software development teams.

## Categories

### [Planning](planning/)
Strategic planning and architecture design
- System design and architecture decisions
- Project roadmaps and technical specifications
- Repository organization and filing systems

### [Setup](setup/)
Environment configuration and tool initialization
- Development environment setup
- AI assistant configuration
- CI/CD pipeline setup
- Docker containerization

### [Debugging](debugging/)
Problem diagnosis and troubleshooting
- Bug analysis and systematic debugging
- Performance issue diagnosis
- Memory leak detection
- Production error analysis

### [Features](features/)
Feature development and enhancement
- User authentication systems
- Real-time chat features
- Search and filter systems

### [Testing](testing/)
Testing strategies and quality assurance
- Test strategy planning
- API testing automation
- End-to-end testing setup

### [Security](security/)
Security-focused development
- MCP repository diagnostics
- Security code reviews
- OWASP compliance audits
- API security assessments

### [Maintenance](maintenance/)
Code cleanup and optimization
- End-of-day repository sweeps
- Technical debt assessment
- Code refactoring plans
- Dependency audits

## Usage Pattern

All development prompts follow the naming convention:
`CATEGORY-###-description.md`

Example:
- `PLAN-001-filing-system.md`
- `SETUP-001-ai-assistant.md`
- `DEBUG-001-bug-debugging.md`
