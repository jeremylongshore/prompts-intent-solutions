## The Prompt

```
You are a copywriter who makes products irresistible to buyers.

Write a product description for [PRODUCT_NAME] that sells to [TARGET_CUSTOMER].

Structure:
1. Hook headline (benefit + intrigue)
2. The problem this solves (emotional connection)
3. How it works (simple explanation)
4. What makes it different (unique advantage)
5. Social proof (testimonials/results)
6. Immediate action (clear CTA)

Include:
- Price anchoring if applicable
- Risk reversal (guarantee/trial)
- Urgency element (limited time/stock)

Tone: [BRAND_VOICE]
Length: 200-300 words
Focus: Benefits over features

Variables:
- [PRODUCT_NAME]: Name and brief description of product
- [TARGET_CUSTOMER]: Specific audience (busy moms, small business owners, etc.)
- [BRAND_VOICE]: Professional, casual, luxury, technical, etc.
```

## Variations by Product Type

### Physical Products
```
Focus on:
- Tangible benefits (how life improves)
- Quality/durability proof
- Shipping/return policies
- Customer photos/reviews
```

### Digital Products
```
Focus on:
- Immediate access/results
- Learning outcomes
- Support/community access
- Skill transformation
```

### Services
```
Focus on:
- Process explanation
- Time/outcome guarantees
- Expertise demonstration
- Client success stories
```

### B2B Software
```
Focus on:
- ROI calculations
- Implementation ease
- Integration capabilities
- Team productivity gains
```

## Power Words That Sell

### For Pain Points
- Frustrated, struggling, tired of, hate
- Wasting time/money, missing out
- Complicated, overwhelming, confusing

### For Solutions
- Automatic, instant, effortless, simple
- Guaranteed, proven, tested, verified
- Finally, breakthrough, game-changer

### For Urgency
- Limited time, while supplies last
- Early bird, exclusive access
- Last chance, ending soon

## A/B Testing Elements

**Test These Components:**
- Headlines (benefit vs curiosity)
- Problem description (emotional vs logical)
- Social proof (testimonials vs statistics)
- CTA button text ("Buy Now" vs "Get Started")
- Price presentation ($49/month vs $588/year)

**Measure These Metrics:**
- Page bounce rate
- Time on product page
- Add-to-cart rate
- Conversion rate
- Average order value

## Common Mistakes

❌ Leading with features instead of benefits
❌ Using generic "professional quality" language
❌ No social proof or testimonials
❌ Vague calls to action
❌ Focusing on company instead of customer
